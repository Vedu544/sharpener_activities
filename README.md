# 💇‍♀️ Salon Booking Application

A full-stack Salon Booking application with a **Node.js backend** and an **Angular frontend**. This project helps manage salon services, bookings, and user interactions efficiently.

---

## 📦 Project Structure

```
root/
│── backend/
│── salon-booking/   (frontend - Angular)
```

---

## 🚀 Backend Setup (Node.js)

Follow these steps to run the backend server:

### 1️⃣ Clone the Repository or Download ZIP

```bash
git clone <repository-url>
```

Or download the ZIP and extract it.

### 2️⃣ Navigate to Backend Folder

```bash
cd backend
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Create Environment File

Create an environment file by referring to:

```
src/config/env.js
```

Make sure to configure all required environment variables correctly (database URL, ports, secrets, etc.).

### 5️⃣ Run Backend Server

```bash
npm run dev
```

✅ Backend will start successfully.

---

## 🎨 Frontend Setup (Angular)

After the backend is running, set up the frontend:

### 1️⃣ Navigate to Frontend Folder

```bash
cd salon-booking
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Angular Development Server

```bash
ng serve
```

🌐 The frontend will be available at:

```
http://localhost:4200
```
