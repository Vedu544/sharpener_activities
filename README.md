# **Expense Tracker - Sharpener**

A full-stack expense tracking app with premium features like filters, leaderboard, and report downloads.

## **How to Run the Project**

1. Download the ZIP or clone the repository.  
2. Open terminal for both `frontend` and `backend` folders.  
3. Run the command `npm run dev` in both terminals.  

That's it!
